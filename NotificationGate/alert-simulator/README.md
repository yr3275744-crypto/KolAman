# סימולטור התראות

הסימולטור מדמה ארבעה גופי ביטחון ששולחים התראות. כל התראה נכתבת כקבצים בתיקייה משלה

## 1. הפעלת הסימולטור

### הפעלה

פתחו טרמינל בתיקיית הסימולטור והריצו את הפקודה המתאימה

```
# Windows
python simulator.py
```
```
# Mac / Linux
python3 simulator.py
```

- בווינדוס אפשר גם להפעיל בלחיצה כפולה על הקובץ `run.bat`

### בזמן הריצה

- ההתראות נכתבות לתיקייה `alerts`
- התיקייה נוצרת ליד הסימולטור בהפעלה הראשונה
- לעצירת הסימולטור לחצו `Ctrl+C`

### חשוב

אין לשנות את קבצי הסימולטור

## 2. איך מגיעה התראה

```
alerts/
├── aman/
├── mossad/
├── pikud-haoref/
└── shabak/
    └── 20260929T110324108_000042/
        ├── alert.json
        └── alert.ready
```

1. כל התראה מגיעה בתיקייה חדשה עם שם ייחודי, בתוך התיקייה של הגוף ששלח אותה
2. בתוך כל תיקיית התראה נוצרים שני קבצים
   - קובץ ההתראה — `alert.json`
   - קובץ סימון ריק, שמסמן שההתראה מוכנה — `alert.ready`
3. קוראים את קובץ ההתראה רק אחרי שקובץ הסימון קיים. כל התראה מקבלת קובץ סימון
4. לאחר הקריאה ניתן למחוק את תיקיית ההתראה
5. ייתכן שכבר ממתינות התראות כשהשירות שקורא את ההתראות עולה

## 3. תוכן ההתראה

```json
{
  "alert_id": "b3f1c2e4-5a6d-4e8f-9a0b-1c2d3e4f5a6b",
  "source": "pikud-haoref",
  "title": "ירי רקטות וטילים",
  "content": "ירי רקטות וטילים לעבר קריית שמונה. יש להיכנס למרחב המוגן תוך 15 שניות.",
  "priority": "CRITICAL",
  "classification": "UNCLASSIFIED",
  "lat": 33.2051,
  "lon": 35.5712,
  "timestamp": "2026-09-29T11:03:23.108Z",
  "status": "WAITING"
}
```

- השדה `alert_id`
  - מחרוזת. מזהה ייחודי של ההתראה
- השדה `source`
  - מחרוזת. הגוף ששלח את ההתראה, זהה לשם התיקייה
- השדה `title`
  - מחרוזת. אחת הכותרות שבסעיף 4
- השדה `content`
  - מחרוזת. טקסט ההתראה
- השדה `priority`
  - מחרוזת. רמת הדחיפות, מהגבוהה לנמוכה — `CRITICAL > HIGH > MEDIUM > LOW`
- השדה `classification`
  - מחרוזת. רמת הסיווג, אחד מהערכים האלה — `UNCLASSIFIED / RESTRICTED / SECRET / TOP_SECRET`
- השדה `lat`
  - מספר. קו רוחב, בין מינוס 90 ל-90
- השדה `lon`
  - מספר. קו אורך, בין מינוס 180 ל-180
- השדה `timestamp`
  - מחרוזת. זמן השליחה בשעון אוניברסלי, באותו פורמט כמו בדוגמה שלמעלה
- השדה `status`
  - מחרוזת. בהתראה חדשה הערך ביצירה תמיד — `WAITING`

## 4. סוגי כותרות התראה 

### אמ"ן — `aman`
- זוהה שיגור רקטות
- זוהה שיגור טיל בליסטי
- זוהו הכנות לשיגור
- זוהה כלי טיס בלתי מאויש עוין
- תנועת כוחות חריגה סמוך לגבול
- שיבושי ניווט באזור

### מוסד — `mossad`
- התרעה על כוונה לפגוע ביעד ישראלי בחוץ לארץ
- זוהה נתיב הברחת אמצעי לחימה
- פעילות חריגה באתר אסטרטגי
- ניסיון כניסה של פעיל עוין לישראל
- העברת כספים לארגון טרור
- תנועת פעיל עוין בין מדינות

### פיקוד העורף — `pikud-haoref`
- ירי רקטות וטילים
- חדירת כלי טיס עוין
- חדירת מחבלים
- התרעה מקדימה
- רעידת אדמה
- האירוע הסתיים

### שב"כ — `shabak`
- התרעה חמה לפיגוע
- תנועת מחבל מבוקש
- חשד לחדירה ליישוב
- רכב חשוד
- חשד לפעילות ריגול עבור גורם עוין
- גניבת אמצעי לחימה

## 5. אזורים

- קובץ האזורים — `regions.geojson`
  - הקובץ מגדיר שלושה אזורים — `NORTH / CENTER / SOUTH`
- האזור של כל נקודה שלא נמצאת באף אחד משלושת האזורים — `OVERSEAS`
- הסדר שבו כתובה כל נקודה בקובץ: קו האורך ראשון — `[lon, lat]`
- אף התראה לא נמצאת על גבול בין אזורים

## 6. מקרים שצריך להכיר

- כתיבה הדרגתית: קובץ ההתראה נכתב בהדרגה, ולכן קוראים אותו רק אחרי שקובץ הסימון קיים
- מטחים: עד 20 התראות בתוך כמה שניות
- התראה לא תקינה: חלק מההתראות יגיעו בצורה לא תקינה, ואתם נדרשים לטפל בהן. למשל
  - קובץ שאי אפשר לקרוא, כי התוכן שלו שבור
  - שדה חסר
  - שדה עם ערך שגוי, כמו קו רוחב שאינו מספר או שנמצא מחוץ לטווח
- שידור חוזר: חלק מההתראות נשלחות יותר מפעם אחת, ואתם נדרשים לטפל בכך

## 7. הערות טכניות

### מטחים בסי-שארפ

רכיב מעקב הקבצים של סי-שארפ שומר אירועים בזיכרון קטן. במטח הזיכרון הזה מתמלא, והתראות הולכות לאיבוד בלי שנזרקת חריגה

כדי שזה לא יקרה, הגדילו את הזיכרון לגודל המקסימלי לפני שמפעילים את המעקב

```csharp
var watcher = new FileSystemWatcher(path);
watcher.InternalBufferSize = 65536;
```

### עברית בקובץ ההתראה

העברית שמורה בקובץ כקודים ולא כאותיות. כך זה נראה כשפותחים את הקובץ בעורך

```
"title": "\u05d9\u05e8\u05d9 \u05e8\u05e7\u05d8\u05d5\u05ea \u05d5\u05d8\u05d9\u05dc\u05d9\u05dd",
```

זה תקין. קריאה רגילה של הקובץ מחזירה את הטקסט בעברית, ואין צורך בשום טיפול מיוחד

### עברית בקונסול

עברית שמודפסת לקונסול עלולה להופיע כסימני שאלה, או באותיות בסדר הפוך. זו מגבלה של חלון הקונסול בלבד, והנתונים עצמם תקינים

## 8. הרצה בדוקר

- הסימולטור והשירות שקורא את ההתראות צריכים לרוץ באותו מקום: שניהם על המחשב, או שניהם בדוקר
- בדוקר, הוסיפו את הסימולטור לקובץ הקומפוז שלכם בדיוק כמו בדוגמה
- תיקיית ההתראות משותפת לסימולטור ולשירות שקורא את ההתראות, דרך וולום בשם `alerts`
- אין להחליף את הוולום ב־`bind mount`
- דרך תיקייה משותפת עם המחשב, אירועי יצירת הקבצים לא מגיעים לקונטיינר, ומעקב הקבצים לא מזהה התראות חדשות
```yaml
services:
  simulator:
    image: python:3.12-slim          # any Python image
    volumes:
      - ./alert-simulator:/sim       # path to the simulator folder
      - alerts:/sim/alerts
    command: ["python", "/sim/simulator.py"]

  my-app:                            # your service
    volumes:
      - alerts:/alerts               # alerts appear here

volumes:
  alerts:
```
